Hardware Prototyping & Mechatronic System Design
Complete mechanical and hardware design, prototyping, and implementation of an automated mechatronic system utilizing AutoCAD for technical modeling and Arduino for closed-loop control.
Key Objectives
Mechanical Design & Modeling: Developed detailed 2D/3D technical drawings, spatial layouts, and assembly plans using AutoCAD.
Mechatronic Integration: Interfaced DC/stepper motors, actuators, and various environmental/positional sensors with an Arduino microcontroller.
Prototyping & Testing: Built and tested a fully functional physical prototype, integrating hardware wiring and software control logic.
Tools & Contents
Hardware & Software: Arduino IDE, AutoCAD, Microcontrollers, Motors, Sensors, Circuit Wiring.
